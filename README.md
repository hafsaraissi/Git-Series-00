# Git-Series-00
Ceci est utilisé pour apprendre les bases de Git et GitHub
## Introduction

Ce dépôt me sert à apprendre en pratiquant les bases de Git et GitHub.

Je découvre Git et GitHub pour la première fois dans le cadre de mon master (Sciences Numérique pour la Santé, parcours IDS) à l'Université de Montpellier.

J'ai hâte d'approfondir mes compétences sur ces outils, essentiels pour la gestion de projets en analyse de données.

## Ma motivation

Passionnée par la robotique, je vois Python et R comme des outils indispensables pour donner vie à mes idées, du traitement de données jusqu'à l'analyse de capteurs.

Mon projet de recherche en localisation par fusion de capteurs m'a déjà montré à quel point la maîtrise de ces langages est essentielle pour progresser efficacement.

Git, de son côté, représente pour moi bien plus qu'un outil technique : c'est une façon de structurer ma pensée et de garder une trace claire de mon évolution.

J'aborde cet apprentissage avec curiosité, en gardant toujours en tête mon objectif de poursuivre en doctorat après ce master.

Chaque ligne de code écrite aujourd'hui est, à mes yeux, une brique de plus vers le parcours scientifique que je veux construire.
